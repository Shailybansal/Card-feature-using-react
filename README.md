# 🎭 React User Card

A simple React application that displays a user card featuring an actress's photo, name, and description. This project demonstrates the basics of React components, JSX, CSS styling, and image importing.

##  Preview

The application displays a card containing:
- Actress's Photo
- Name
- Short Description

## 🚀 Features

- Built with React
- Functional Components
- JSX Syntax
- CSS Styling
- Local Image Import
- Responsive Card Layout

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6)
- HTML5
- CSS3
- Vite

## 📂 Project Structure

```
src/
│── assets/
│     └── actress-image.png
│
│── components/
│     ├── UseCard.jsx
│     └── UseCard.css
│
│── App.jsx
│── main.jsx
```

## 📦 Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/react-user-card.git
```

2. Navigate to the project folder

```bash
cd react-user-card
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```
